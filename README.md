#  Tela de Login Simples

Um projeto de front-end simples, criado para fins de estudo, que implementa uma tela de login estilizada com HTML e CSS puro.

## 🚀 Sobre o Projeto

Este é um exercício prático para desenvolver habilidades em HTML e CSS. O projeto consiste em uma página única com um formulário de login centralizado, utilizando um fundo com gradiente e um design minimalista.

### ✨ Funcionalidades

- Interface de usuário limpa e centralizada.
- Campos para inserção de "Usuário" e "Senha".
- Botão de envio com efeito `hover`.
- O formulário está preparado para enviar os dados para um script `login.php` (backend não implementado).

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram usadas na construção do projeto:

- **HTML5**: Para a estrutura da página e do formulário.
- **CSS3**: Para a estilização, incluindo:
  - `linear-gradient` para o fundo dinâmico.
  - `position` e `transform` para centralização de elementos.
  - `rgba` para a transparência da caixa de login.
  - Pseudo-classes como `:hover` para interatividade.

---

## 📖 Como Usar

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador web.

E pronto! A tela de login será exibida.
